# 128.最长连续序列
**日期**：2026.11.19
**题目链接**:https://leetcode.cn/problems/longest-consecutive-sequence/description/

# 方法一
```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        if(nums.empty()) return 0;
        sort(nums.begin(),nums.end());
        int ans = 1;
        int count = 1;
        for(int i = 1;i < nums.size();i++){
            if(nums[i - 1] == nums[i]) continue;
            else if(nums[i - 1] + 1 == nums[i]) count++;
            else count = 1;
            ans = max(ans,count);
        }
        return ans;
    }
};
```

# 方法二(哈希表)

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> st(nums.begin(),nums.end());
        if(st.empty()) return 0;
        int ans = 1;
        for(auto & x :st){
            if(st.count(x - 1)) continue;
            // x为起点，正向计算
            int y = x;
            int count = 1;
            while(st.count(y + 1)){
                count++;
                y = y + 1;
                ans = max(ans,count);
            }
        }
        return ans;
    }
};
```





# 总结

| 容器 | 存什么 | 类比 |
|---|---|---|
| `unordered_map<Key, Value>` | 键 + 值 配对 | 通讯录：姓名 → 电话 |
| `unordered_set<Key>` | 只有键，没有值 | 签到表：只有名单，问"某人来没来" |

// map：每个 key 挂着一个 value
unordered_map<string, int> mp;
mp["apple"] = 3;            // 存的是"apple → 3"这个配对
mp.count("apple");          // apple 存在吗？
mp["apple"];                // 还能取出它对应的 3

// set：只有元素本身
unordered_set<int> st;
st.insert(5);               // 只放一个 5，没有"挂"任何东西
st.count(5);                // 5 在吗？→ 1
st.count(9);                // 9 在吗？→ 0

| 操作 | unordered_map | unordered_set |
|---|---|---|
| 插入 | `mp[key] = v;` | `st.insert(x);` |
| 查询存在 | `mp.count(k)` | `st.count(x)` |
| 取值 | `mp[k]` | ❌ 没有 value 可取 |
| 删除 | `mp.erase(k)` | `st.erase(x)` |
| 遍历 | `for(auto& [k, v] : mp)` | `for(auto& x : st)` |
| 大小 | `mp.size()` | `st.size()` |
