# 方法一（暴力遍历）

```cpp
class Solution{
public:
    vector<int> twoSum(vector<int>& nums,int target){
        int n = nums.size();
        for(int i = 0;i < n;i++){
            for(int j = i + 1;j < n;j++){
                if(nums[i] + nums[j] == target)
                    return {i,j};
            }
        }
        return {};
    }
};
```

# 方法二（哈希表）

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> hashtable;
        for (int i = 0; i < nums.size(); ++i) {
            auto it = hashtable.find(target - nums[i]);
            if (it != hashtable.end()) {
                return {it->second, i};
            }
            hashtable[nums[i]] = i;
        }
        return {};
    }
};
```

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        // 1. 准备一个空的小本本（字典）
        // 键(int)：存数组里的数字
        // 值(int)：存这个数字对应的下标（页码）
        unordered_map<int, int> hashtable; 
        
        // 2. 开始挨个遍历数组
        for (int i = 0; i < nums.size(); i++) {
            // 3. 算出你心里想要的“另一半”是多少
            int complement = target - nums[i];
            
            // 4. 去小本本里查，之前有没有见过这个“另一半”
            // count 返回 1 代表有，0 代表没有
            if (hashtable.count(complement)) {
                //count()函数统计某个key出现的次数 key是唯一的，不能重复
                // hashtable[complement] 是之前那个数字的下标
                // i 是当前这个数字的下标
                return {hashtable[complement], i};
                //complement是key，也就是要找的数组，hashtable[complement]是对应的下标
            }
            
            // 6. 没找到另一半，那就把当前的自己记在小本本上
            // 键是当前数字，值是当前下标
            hashtable[nums[i]] = i;
        }
        
        return {}; // 兜底，没找到返回空
    }
};
```

# 总结
1.C和C++对于数组的不同之处

在 C++ 里，用 vector 确实不需要提前声明数组的固定长度，它可以动态变化。

int arr[3] = {1, 2, 3};

vector<int> arr = {1, 2, 3};

2.二者的访问方式相同

printf("%d",arr[0]);

cout << arr[0];

3.哈希表和数组对比

数组占用连续的空间，而哈希表不是
数组在声明时声明大小，而哈希表是动态的，不需要提前声明
数组下标是连续的，而哈希表的键是任意的

举例：数组的下标是连续的，如果你用了下标 20240001，就意味着系统必须从下标 0 开始，一直排到 20240001，前面的 20240000 个位置哪怕全空着，也必须得建出来。

对于数组地址的确定方法：实际内存地址 = 数组的起始地址 + 下标 × 每个元素占的字节数 O(1)

4.哈希表知识点

通过键(key)找值(value) O(1)
通过值(value)找键(key)，则需要遍历整个字典

在设计时，一定要把**想要查询的线索**作为键

哈希表的“映射”：x--y，但不能是通过y找x
例：2 % 100 = 102 % 100 = 2 (哈希冲突)
