# 1.两数之和（cpp）
**日期**：2026.11.18
**题目链接**:https://leetcode.cn/problems/two-sum/description/

```c
int c_arr[3] = {1, 2, 3};       // C 语言数组
vector<int> cpp_vec = {1, 2, 3}; // C++ vector

cout << c_arr[0]; // 输出 1
cout << cpp_vec[0]; // 输出 1 （用法完全一样）

```cpp
class Solution{
public:
    vector<int> twoSum(vector<int>& nums,int target){
        int n = nums.size();
        for(int i = 0;i < n;i++){
            for(int j = i + 1;j < n;j++){
                if(nums[i] + nums[j] == target)
                    return {i,j};
            }
        }
        return {};
    }
};
```


# 总结
1.C和C++对于数组的不同之处
在 C++ 里，用 vector 确实不需要提前声明数组的固定长度，它可以动态变化。

int arr[3] = {1, 2, 3};

vector<int> arr = {1, 2, 3};

2.二者的访问方式相同

printf("%d",arr[0]);

cout << arr[0];
