# 错题总结：groupAnagrams（计数法）

> 
> 日期：2026-11-26
> 题目：字母异位词分组（LeetCode 49）
> 我的解法：字符计数拼 key + 哈希表分组

---

## 一、代码中出现的问题

### 1. 以为 map 有 mp.key/mp.value（语法错误）

```
mp.key += … // ❌ map 不存在这种语法
```

**正确的取值方式**：

表格

| 想要什么 | 写法 |
| --- | --- |
| 遍历时的 key | `p.first` |
| 遍历时的 value | `p.second` |
| 已知 key 取 value | `mp[key]` |

### 2. 整数直接 += 到 string（语法错误）

```
key += hash[i]; // ❌ 整数被当字符码，产生乱码
```

整数转字符串必须用 `to_string`：

```
key += to_string(hash[i]); // ✅ 5 → "5"
```

### 3. mp.value = str 方向反了（逻辑错误）

```
mp.value = str; // ❌ 语义是"整个替换 value"，不是"追加 str"
```

正确做法：`mp[key].push_back(str);`

---

## 二、相关知识点

### 1. push_back 的使用规则

- push_back 是 **vector 的成员函数**，谁是 vector 谁就能用
- `mp[key]` 的 value 是 vector → `mp[key].push_back(str)` 合法
- `unordered_map` 本身不是 vector → 不能 push_back
- **push_back = 追加；`=` = 整个替换**（不要搞混！）

### 2. pair 取值：first /second

```
for(auto& p : mp){
    p.first // key
    p.second // value
}
```

### 3. string 相关

- string **没有**成员函数 `.sort()`，用全局 `sort(s.begin(), s.end())`
- 整数转字符串：`to_string(x)`
- 字符串拼接：`key += "abc"`

### 4. 字符计数模板（哈希计数法）

```
int hash[26] = {0};
for(auto& c : str){
    hash[c - 'a']++; // 字母 → 下标 0~25
}
```

- `c - 'a'` 把字符映射到下标
- `int hash[26] = {0}` 放在**每个单词的循环内**，每个单词重新计数

### 5. 异位词分组的两种 key 方案

表格

| 方案 | key 举例 | 复杂度 |
| --- | --- | --- |
| 排序法 | "eat" → "aet" | O(k log k) |
| **计数法（本次独立想出 ✅）** | "1#0#1#...#" | O (k)，更优 |

## 三、正确代码（修正版）

```
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> mp;
        for(auto& str : strs){
            int hash[26] = {0};
            for(auto& c : str){
                hash[c - 'a']++;
            }
            string key = "";
            for(int i = 0; i < 26; i++){
                key += to_string(hash[i]);
                key += '#';
            }
            mp[key].push_back(str);
        }
        vector<vector<string>> res;
        for(auto& p : mp){
            res.push_back(p.second);
        }
        return res;
    }
};
```
