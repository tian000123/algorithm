对于一个数组中有多个单词如何进行遍历？

```c
#include<stdio.h>

int main(){
    char* str = “abc”;
    int n = 3;
    for(int i = 0;i < 3;i++){
        printf("%c ",str[i]);
    }
    // 输出 a b c
    printf("\n");
    for(int j = 0;str[j] != '\0';j ++){
        printf("%c\n",str[j]);
    }
    //输出
    // a
    // b
    // c
    return 0;
}
```

其中，`sizeof` 算的是占用内存的总字节数，除以每一个大小来计算元素个数

求元素个数，在C中，用sizeof()/每一个sizeof(),在cpp中直接.size()求个数
sizeof() = 占用字节数
.size() = 元素个数

注：带()的是函数，有的需要传参，有的不需要

| | `sizeof(x)` | `x.size()` |
|---|---|---|
| 语言 | C 和 C++ 都有 | 只有 C++ |
| 本质 | 编译期运算符 | 运行时成员函数 |
| 问的问题 | 占多少字节内存 | 装了几个元素 |
| 对 C 数组 | `sizeof(arr)/sizeof(arr[0])` 求长度 | ❌ C 数组没有 `.size()` |
| 对 string | 对象自身字节数（无意义） | 字符个数 ≈ strlen |
| 对 vector | 对象自身字节数（无意义） | 元素个数 ✅ |
